## Hotlinking Patterns & Sizing Params

**Unsplash** (imgix-backed CDN, stable hotlink form):
```
https://images.unsplash.com/photo-{ID}?auto=format&fit=crop&w={width}&q={quality}
```
- `w=` width in px (CDN resizes; never ship full raw). `h=` + `fit=crop` for fixed aspect; add `crop=entropy` or `crop=faces` for smart cropping.
- `q=` quality 1–100 (75–80 is the sweet spot).
- `auto=format` serves AVIF/WebP to supporting browsers (biggest bandwidth win).
- `dpr=2` for retina at the same `w`.
- Recommended: hero `w=2000&q=80`, portfolio card `w=800&q=75`, thumbnail `w=400&q=70`.
- Caveat: for a production *app* Unsplash's guidelines prefer API usage (with download-event pings); for a marketing site, hotlinking `images.unsplash.com` is standard and CDN-supported, but downloading and self-hosting (e.g., on R2) is the most robust option and fully allowed by the license.

**Pexels**:
```
https://images.pexels.com/photos/{ID}/pexels-photo-{ID}.jpeg?auto=compress&cs=tinysrgb&w={width}
```
- Params: `w=`, `h=`, `fit=crop`, `dpr=`, `auto=compress`, `cs=tinysrgb`.
